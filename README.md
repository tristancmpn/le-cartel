# Le Cartel

App de rangement de la coloc (PWA hébergée sur GitHub Pages, données dans Supabase).

- **Quotidien** : chacun note les petites tâches qu'il a faites.
- **Semaine** : grosses tâches de la semaine, on se nomine puis on valide.
- **Stats** : qui a fait quoi, par jour, semaine, mois, année.
- **Rappels** : notifications iPhone (app ajoutée à l'écran d'accueil).

La maquette d'origine est dans `preview/`.
